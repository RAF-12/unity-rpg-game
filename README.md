# 🛡️ Proyecto RPG - Unity & C#

Proyecto de videojuego de rol (RPG) desarrollado en Unity, enfocado en la implementación de sistemas de juego avanzados, lógica de personajes, gestión de inventarios y patrones de programación orientada a objetos en C#.

## 🛠️ Tecnologías y Herramientas
* **Motor:** Unity (2D / 3D)
* **Lenguaje:** C#
* **Control de versiones:** Git / GitHub

## 🚀 Características Técnicas
* **Arquitectura de Juego:** Implementación de componentes modulares en C# para la separación de responsabilidades (controladores de jugador, sistemas de combate y estadísticas).
* **Gestión de Datos:** Estructuras para el manejo de inventarios, objetos y progresión del personaje.
* **Inteligencia Artificial:** Configuración de comportamientos y estados básicos para enemigos o NPCs.
* **Interfaz de Usuario (UI):** Conexión dinámica entre la lógica del juego y los elementos visuales de la interfaz (HUD, menús y barras de vida/estado).

## 📂 Estructura del Repositorio
El repositorio incluye los directorios esenciales del proyecto para garantizar su correcta compilación:
* `Assets/` - Scripts en C#, prefabs, escenas, materiales y recursos visuales.
* `Packages/` - Dependencias y paquetes del proyecto.
* `ProjectSettings/` - Configuraciones globales del motor Unity.
